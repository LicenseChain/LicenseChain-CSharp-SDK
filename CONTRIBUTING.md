Thanks for helping improve this SDK. Maintained by **LicenseChain** ([support@licensechain.app](mailto:support@licensechain.app)).

## Development setup

```bash
dotnet build
dotnet test
```

## Guidelines

- Use conventional commits: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`
- Keep changes focused; match existing project style
- Never commit secrets, API keys, or `.env` files
- Open an issue before large design changes when possible

## Pull requests

1. Branch from `main`
2. Ensure the commands above pass locally
3. Describe the change and link related issues
4. Confirm your contribution complies with the ELv2 license terms
